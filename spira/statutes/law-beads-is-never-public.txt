A beads database is never public and never ships with the harness. It accumulates internal working notes, agent memories and the overseer's own judgement, none of which are code. Keep every beads backup repository private, keep .beads, *.db and issue exports out of any shared repository, and enforce it with a hook that refuses the commit rather than a habit of remembering. The harness is shareable; the database it operates on belongs to whoever runs it.
