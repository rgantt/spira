Before diagnosing a red pull request, check whether it is behind its base. A required check tests the request head, not the merge result, so a fix landing on the base never re-runs the requests it repairs and they rot red in place. Update the branch first and re-read the result; only a request red on the CURRENT base has a fault of its own. Nine once failed on the identical two legs from runs predating the two fixes already merged, and looked like nine separate bugs.
