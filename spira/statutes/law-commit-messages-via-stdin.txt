Never pass prose through a shell argument. Backticks and $( ) inside double quotes are command substitution, so a commit message, a bead comment or a pull-request body silently loses the very terms it was explaining — twice in commit messages, then again in a bead comment where two command names vanished mid-sentence. Write the text to stdin with a quoted heredoc, or to a file, and pass that: `git commit -F -`.
